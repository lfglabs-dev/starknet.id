# Starknet.ID

Your decentralized identity on Starknet.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Colors

- Primary (Dark Green): `#0C8654`
- Background (White-Green): `#FCFFFE`
- Secondary (Dark Blue): `#122845`

## Page Reveal Animation

The website features a smooth page reveal animation on load and route changes. The animation splits a dark green overlay from the center outwards, revealing the page content underneath with a fade-in effect.

The animation respects `prefers-reduced-motion` for accessibility and does not block content when JavaScript is disabled.
